A program that draws a one-page newspaper front page summing up the world news of Monday, 23 November 2026 — seven verified stories, from Trump's New Year deadline on Iran to a strike grounding every flight in Belgium — and writes it to /output/entry.png. The image is drawn entirely in code (a hand-built 5x7 bitmap font and a small PNG encoder, Node standard library only): no network, no image files, and the same bytes come out of every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
